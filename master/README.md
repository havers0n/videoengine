# Master Dataset

Эта директория содержит "чистый" агрегированный датасет по всем runs.

## Файлы

- `dataset.json` - агрегированный датасет всех вариантов из всех runs
- `ignore.json` - глобальный список вариантов и паттернов для исключения
- `scoring.json` - версионированные веса для scoring

## Структура dataset.json

Каждая запись содержит:
- Все фичи варианта (из анализа)
- `run_id` - идентификатор run, из которого вариант был добавлен
- `ingested_at` - дата добавления в master dataset

## Обновление

Master dataset автоматически обновляется при каждом ингесте нового run через `npm run ingest`.

## Версионирование

- `ignore.json` и `scoring.json` версионируются вручную
- Изменения должны быть обоснованы и задокументированы
